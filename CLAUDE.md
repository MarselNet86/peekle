# CLAUDE.md

Peekle: оверлей поверх Claude Code для macOS. Перед тем как писать что-либо, читай `tech.md`. Он единственный источник истины по стеку, контрактам, типам, окнам, конфигу, конвенциям и роадмапу слайсов. Текущая версия ядра указана в его шапке.

Репозиторием владеет один человек и играет обе роли: тимлид и разработчик. Файлов ролей нет. Контракты живут в `tech.md`, правила сессии в этом файле.

## Жёсткие правила

1. **Подчиняйся `tech.md` дословно.** Типы, формы эндпоинтов, имена команд и событий, флаги окон, ключи конфига берутся оттуда буквально.
2. **Контракты не выдумываются.** Нет типа, поля, эндпоинта, события, команды или ключа конфига: СТОП и блок `CONTRACT GAP` из секции 13. Код против выдуманного типа не пишется. Едем на локальной заглушке, изменение контракта ложится первым отдельным коммитом с бампом версии.
3. **Один слайс за раз.** Реализуй одну задачу из роадмапа (секция 14) и отдай сфокусированный дифф. Не скаффолди остальное приложение просто потому, что оно рядом.
4. **Ни один фичевый слайс не начинается до зелёного чек-листа каркаса.** Чек-лист в секции 14. Всё или ничего.
5. **Тесты часть слайса.** Выводи их из критериев приёмки задачи, а не из кода, который только что написал. Шесть обязательных типов в секции 10. Слайс без них не мёржится.
6. **Фикстуры захватываются, а не пишутся.** Всё в `fixtures/hooks/` приходит с живой сессии Claude Code через `scripts/capture-hooks.sh`. Payload, написанный руками и расходящийся с реальностью, хуже отсутствия теста.
7. **Сгенерированный код не источник.** `src/lib/types/generated/` производит `ts-rs`. Правь тип в Rust и перегенерируй.
8. **Используй примитивы.** Любой визуальный элемент приходит из `src/lib/ui`. Нет нужного примитива: это изменение контракта секции 9, а не локальная кнопка.
9. **Коммить по ходу.** Маленькие логические коммиты, Conventional Commits, английский, императив. Полные правила в секции 12.
10. **Не нарушай инвариант разрешения.** Каждый блокирующий запрос хука разрешается ровно один раз на каждом пути: ответ, отмена, таймаут, байпас, ошибка. Утёкший pending вешает живой прогон агента.
11. **Секреты не логируются.** Токен сервера, OAuth-токен и содержимое Keychain не попадают ни в логи, ни в трейсы, ни в сообщения об ошибках. В `tracing` идёт длина, не значение.
12. **Диалог Keychain только по действию пользователя.** Никаких запросов доступа на старте приложения или из фонового опроса.

## Рабочий цикл слайса

1. Прочитай слайс в секции 14: цель, свои файлы, затрагиваемые контракты, критерии приёмки, тесты.
2. Проверь, что нужные контракты есть в секции 6. Нет: `CONTRACT GAP` и стоп.
3. Копируй раскладку эталонной вертикали (путь island-тоста из стадии 1). Это шаблон, а не пример: та же структура файлов, то же использование bridge, та же раскладка тестов, тот же нейминг.
4. Сначала напиши приёмочные тесты из критериев.
5. Реализуй. Коммить по ходу.
6. Прогони гейт локально: `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test`, `pnpm lint`, `pnpm check`, `pnpm test`, `pnpm test:e2e`, `pnpm tauri build --debug`.
7. Открой PR с id слайса в заголовке, например `S4 usage bars`. Тело: что делает, какие контракты затрагивает, чем покрыто.
8. Пройди чек-лист ниже до мёрджа.

## Чек-лист самопроверки

Механически, каждый пункт, каждый PR:

- [ ] нет выдуманных типов, всё трассируется в секцию 6 `tech.md`
- [ ] нет правок вне своих файлов слайса, кроме контрактного коммита, который лёг раньше
- [ ] тесты проверяют контракт, а не реализацию
- [ ] каждый блокирующий путь разрешается ровно один раз, включая ошибку и таймаут
- [ ] UI собран из `src/lib/ui`, ничего самописного в папке фичи
- [ ] фикстуры хуков захвачены, а не написаны
- [ ] типы перегенерированы, дерево чистое
- [ ] нет `unwrap` вне тестов, и никогда в хендлере хука
- [ ] токены и credentials не утекли в логи и в сообщения об ошибках
- [ ] не добавлено ни иконки в доке, ни трея, ни кнопки закрытия, ни непрозрачной поверхности на весь экран
- [ ] коммиты по формату, закомментированного кода не осталось

## Среда

macOS 13+, Node 20+, pnpm, Rust из `rust-toolchain.toml`. Запуск в dev: `pnpm tauri dev`. Всё внешнее в dev по умолчанию за фейками (`[usage] provider = "fake"` и фейки секции 7), поэтому сессия не ждёт ни реальных данных, ни реальных разрешений, ни залогиненного Claude Code.

## Дисциплина письма

Активный залог, императив, конкретика. Без филлеров, без маркетинга, без эмодзи. Всё в репозитории на английском: код, комментарии, коммиты, тексты PR, UI-копия. На русском только `tech.md` и этот файл.
